Conhecendo o Bootstrap

A ferramenta que tornou este projeto possível

Esta página faz parte de um projeto educacional e explica o framework utilizado no desenvolvimento deste site.

O que é Bootstrap?

Bootstrap é um framework front-end de código aberto criado em 2011 por desenvolvedores do Twitter. Ele fornece uma coleção de CSS e JavaScript prontos para a construção de interfaces web: sistemas de grid, componentes (botões, cards, menus) e utilitários de estilização.

Na prática, ele funciona adicionando classes CSS aos elementos HTML. Por exemplo, a classe btn btn-primary transforma um botão comum em um botão estilizado do Bootstrap, sem escrever nenhuma linha de CSS próprio.

É atualmente o framework CSS mais popular do mundo, utilizado por milhões de sites, e é a ferramenta utilizada neste projeto.

Para que serve?

O Bootstrap resolve problemas comuns do desenvolvimento front-end:

Produtividade

Componentes prontos evitam "reinventar a roda". Um menu ou card leva minutos, não horas.

Responsividade

O sistema de grid já vem preparado para funcionar em celulares, tablets e desktops sem CSS extra.

Padronização

Botões, cores e espaçamentos seguem um padrão visual consistente, mesmo em equipes grandes.

Sistema de Grid

O grid do Bootstrap divide a página em 12 colunas imaginárias. Combinamos três classes para montar o layout:

  • container — envolve o conteúdo e centraliza a página com largura máxima;
  • row — cria uma "linha" que agrupa as colunas;
  • col — define as "colunas" e quanto espaço cada uma ocupa.

Também usamos breakpoints como col-md-6 e col-lg-4 para dizer como as colunas se comportam em cada tamanho de tela. 

<div class="container">      <!-- envolve a página -->
  <div class="row">           <!-- linha -->
    <div class="col-md-6">Conteúdo 1</div>
    <div class="col-md-6">Conteúdo 2</div>
  </div>
</div>

Responsividade

Design responsivo é a técnica de construir páginas que se adaptam automaticamente ao tamanho da tela do dispositivo. O Bootstrap usa a abordagem mobile-first: o estilo padrão é feito para celulares, e as classes com prefixos (sm, md, lg, xl) aplicam mudanças em telas maiores.

Isso significa que um único código funciona em todos os dispositivos:

Prefixo da classe A partir de... Dispositivo típico
col-* (nenhum)0px📱 Celulares
col-sm-*≥ 576px📱 Celulares maiores
col-md-*≥ 768px📱 Tablets
col-lg-*≥ 992px💻 Notebooks
col-xl-*≥ 1200px🖥️ Monitores
col-xxl-*≥ 1400px🖥️ Monitores grandes

Como o Bootstrap foi incluído neste projeto

A forma mais simples de usar o Bootstrap é via CDN (servidor externo), sem baixar nenhum arquivo. Basta adicionar estas linhas no HTML: 

<!-- CSS do Bootstrap (dentro do <head>) -->
<link href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css" rel="stylesheet">

<!-- JavaScript do Bootstrap (antes de fechar o </body>) -->
<script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>
