A linguagem que dá vida às páginas web

O que é JavaScript?

JavaScript (JS) é uma linguagem de programação criada em 1995 por Brendan Eich. Ela roda diretamente no navegador e é responsável pelo comportamento das páginas: permitir que o site reaja a cliques, valide formulários, atualize conteúdos e responda ao usuário sem precisar recarregar.

Diferente do HTML (que marca o conteúdo) e do CSS (que define o estilo), o JavaScript é uma linguagem de programação completa, com variáveis, funções, condições e laços de repetição. Hoje ela também roda fora do navegador, no servidor, através do Node.js.

Neste projeto, o toast de confirmação do formulário de contato (página Início) e todas as demos desta página foram programados em JavaScript puro.

HTML + CSS + JavaScript

As três tecnologias base da web — cada uma com um papel:

HTML — Estrutura

Define o conteúdo da página: títulos, textos, imagens, botões.

🏠 É como o esqueleto de uma casa.

CSS — Estilo

Define a aparência: cores, fontes, espaçamentos e layout.

🎨 É como a pintura e a decoração da casa.

JavaScript — Comportamento

Define as ações: o que acontece ao clicar, digitar e interagir.

⚡ É como a eletricidade da casa.

Para que serve?

O JavaScript está presente em praticamente tudo que usamos na internet:

Interatividade

Menus, sliders, botões e animações que reagem ao usuário.

Validação

Confere formulários (e-mail, senha, campos vazios) antes de enviar.

Conteúdo dinâmico

Atualiza a página sem recarregar: feeds, chats, notificações.

Base de frameworks

React, Vue, Angular e Node.js são construídos sobre JavaScript.

Conceitos Básicos

Clique em cada conceito para ver a explicação e um exemplo de código:

Variáveis são espaços para guardar informações na memória. Usamos let para valores que podem mudar e const para valores fixos. 
let idade = 20;        // pode mudar
const nome = "Maria";  // constante (não muda)

idade = 21;   // ✅ permitido
// nome = "Ana";   // ❌ erro! const não muda

O JavaScript trabalha com diferentes tipos de informações: 
let texto  = "Olá!";          // string   (texto)
let numero = 42;              // number   (número)
let ativo  = true;            // boolean  (verdadeiro/falso)
let lista  = [1, 2, 3];       // array    (lista)
let pessoa = { nome: "Ana" }; // objeto   (dados juntos)

Funções são blocos de código que executam uma tarefa e podem ser reutilizados várias vezes, recebendo informações (parâmetros) e devolvendo resultados. 
function saudar(nome) {
  return "Olá, " + nome + "!";
}

saudar("Maria");  // retorna "Olá, Maria!"

Com if / else, o programa escolhe caminhos diferentes dependendo da situação: 
if (idade >= 18) {
  console.log("Maior de idade");
} else {
  console.log("Menor de idade");
}

O for repete um bloco de código várias vezes, evitando escrever a mesma coisa de novo: 
for (let i = 1; i <= 5; i++) {
  console.log("Repetição número " + i);
}

Eventos são ações do usuário (clique, digitação, rolagem) que o código pode "escutar" e responder: 
botao.addEventListener("click", function () {
  alert("Você clicou no botão!");
});

O DOM (Document Object Model) é a representação do HTML na memória do navegador. Com o JavaScript, podemos selecionar e alterar qualquer elemento: 
// seleciona um elemento do HTML
const titulo = document.querySelector("h1");

// altera seu conteúdo e estilo
titulo.textContent = "Novo título";
titulo.style.color = "blue";

Demo 3 — Mostrar / Ocultar

Demonstra condicionais (if) e a classe d-none do Bootstrap.

🎉 Parabéns! Você acabou de usar JavaScript para me revelar! 

btnRevelar.addEventListener("click", () => {
  if (textoSecreto.classList.contains("d-none")) {
    textoSecreto.classList.remove("d-none");  // mostra
    btnRevelar.textContent = "Ocultar mensagem";
  } else {
    textoSecreto.classList.add("d-none");     // esconde
    btnRevelar.textContent = "Mostrar mensagem";
  }
});

Demo 5 — Mini Lista de Tarefas

Demonstra manipulação do DOM: criar, listar e remover elementos.

Nenhuma tarefa ainda. Adicione a primeira! ✏️ 

function adicionarTarefa() {
  const texto = inputTarefa.value.trim();
  if (texto === "") return;   // ignora campo vazio

  // cria os elementos na memória
  const item = document.createElement("div");
  item.className = "todo-item";

  const span = document.createElement("span");
  span.textContent = texto;

  const btnRemover = document.createElement("button");
  btnRemover.className = "btn btn-sm btn-danger";
  btnRemover.textContent = "✕";
  btnRemover.onclick = () => item.remove();  // remove ao clicar

  // adiciona na página de verdade
  item.append(span, btnRemover);
  listaTarefas.appendChild(item);
  inputTarefa.value = "";
}

Onde o JavaScript aparece neste projeto

  • Toast do formulário (página Início) — a mensagem "Mensagem enviada com sucesso" é exibida por um código JavaScript que criamos.
  • Carrossel, Modais e Accordion — as animações e o abrir/fechar desses componentes são controlados por JavaScript.
  • Demos desta página — feitas em JavaScript puro (também chamado de vanilla JS), sem nenhuma biblioteca.
Você sabia? O próprio Bootstrap usa JavaScript por trás! O arquivo bootstrap.bundle.min.js que carregamos no final de cada página é quem faz o menu mobile, os modais e o carrossel funcionarem.
